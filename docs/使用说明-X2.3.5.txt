写作台 · 使用说明（X2.3.5）
==================================

【本版新增（X2.3.5）】
1. 第一次打开会先走一遍「新手引导」，三步：
   ① 认识界面（左边文件树、右边写正文、自动保存/备份）
   ② 选稿子存在哪个盘（可换文件夹，旧稿会一起搬过去）
   ③ 选界面语言、填角色表（可以留空）
   点「完成」或者「跳过」就进正文；以后想再看：设置 → 再看一遍新手引导。
2. 版本号：X2.3.5。

【X2.2.12 更新】
1. 新增「斜体」「下划线」两个按钮（在荧光笔右边）：
   - 选中文字点一下＝加上，再点一下＝取消，按钮高亮表示当前是开的；
   - Ctrl+I / Ctrl+U 也一样能用；
   - 导出 Word（.docx）和 HTML 时会保留斜体和下划线。
2. 修好「莫名打出斜体字」：
   - 以前在描写行里回车，下一行会连「描写行」一起复制，新打的字就自动变灰斜体；
   - 现在在描写行末尾回车，新的一行是普通段落（正常黑字）；在描写行中间回车，后半句会切成普通段落。
   - 注意：描写行本身是灰色斜体，那是它的样式，不是格式错乱；想写成正常段落，回车到新行再写即可。
3. 「清除格式」后，颜色那一格的勾不再跳回黑色：
   - 勾现在跟着「光标前一个字的颜色」走（跟 Word 一样），所以紫色文字清完格式，勾还在紫色上；
   - 荧光笔那排清完会收掉勾（因为确实没有高亮了）。
4. 图标：红底白「写」（没有钢笔）。
5. 版本号：X2.2.12。

【X2.2.8 更新】
1. 「清除格式」不再把文字颜色洗成黑色：
   - 只清荧光笔、粗体、斜体、下划线，颜色保留；
   - 想恢复默认黑，就选中文字后点颜色里的第一个黑块。
2. 荧光笔可以「点一下加、再点一下取消」：
   - 选中文字点黄色 → 加高亮，色块打勾；再点同一个黄色 → 取消高亮，勾也消失；
   - 只有荧光笔这样，文字颜色不受影响。
3. 颜色/高亮现在按标准样式存（span），导出 Word、HTML 时颜色不会丢；旧笔记会自动规范化。

【X2.2.2 / X2.2.1 修复】
1. 清除格式后荧光笔不再打勾（勾只跟着当前选中的字走）。
2. 版本号前缀从 V 改成 X。
3. 角色表里的空白行能保存了：空白行原样保留，下拉里显示「（空白）」，
   选中它就插入无名台词「【】：“”」，光标停在括号里。
4. 「清除格式」会把荧光笔高亮一起清掉（只选中半句时只清那半句）。

【v2.2 新增】
1. 颜色 / 荧光笔有「已选」标记：选中的色块是「红圈 + 白色对勾」。
2. 「回车生成」和右边按钮互相切换：
   回车生成＝台词行 → 右边按钮显示「插入描写行」
   回车生成＝描写行 → 右边按钮显示「插入台词行」
3. 角色表默认是空的（不再自动填「旁白」）：
   - 每行一个角色名，行距拉开、可上下拉大；
   - 想留空就留空，清空后保存会提示「角色表已清空」；
   - 角色表为空时，顶部角色下拉显示「（无角色）」。

【其它功能】
◆ 导出（顶部「导出…」）：范围可选「当前文件 / 整棵树」，格式：
   TXT / Markdown / HTML / Word(.docx) / PDF / Excel(.xlsx) / PowerPoint(.pptx)
   - Word、HTML、PDF 保留颜色、荧光笔和描写行的斜体
   - Excel 两张表：目录清单 + 台词表（场景/行号/类型/角色/台词或描写/字数）
     类型列 = 台词 / 旁白 / 描写，配音、校对时直接筛
   - PPT 每篇文件一页大纲
◆ 剧本模式：每行【角色】：“文本”；回车按「回车生成」的设定生成台词行或描写行；
   Shift+Enter 永远是普通换行。
◆ 左侧层级：父文件＝文件夹图标＋加粗＋「子N · 字数」，子文件＝文件图标＋缩进引导线
◆ 语言：设置 → 语言 → 中文 / 日本語 / English
◆ 字体（顶部下拉）：幼圆、方正舒体、华文琥珀、华文彩云、楷体、华文行楷、隶书、仿宋
◆ 壁纸（设置 → 壁纸）：选图片 / 截图 Ctrl+V / 拖入图片文件；「底纹浓度」可调
◆ 多层子文件：＋子文件、行上＋、右键菜单、底部「父文件」下拉移动
◆ 文字颜色、荧光笔、格线（无/横线/方格/点阵/剧本格线）、字号、深色模式
◆ 右键菜单：新建子文件 / 重命名 / 复制标题 / 展开 / 折叠 / 移到顶层 / 删除
◆ 历史版本（3 分钟一版，最多 8 版）、立即备份/恢复、打开文件夹、搜索、标签
◆ 快捷键：Ctrl+N 新建 · Ctrl+S 备份 · Ctrl+E 导出 · Ctrl+F 搜索

【安装 / 升级】
双击「写作台-安装包-2.3.5.exe」→ 一路下一步，可自选安装目录（覆盖旧版即可，笔记不动）。
第一次运行若 Windows 提示「已保护你的电脑」→「更多信息」→「仍要运行」。
便携版（可选）（连外壳程序一起换了，图标随之更新）：
先把正在运行的旧版关掉，再双击打开；桌面上的「写作台」快捷方式用的就是新图标。
安装版和便携版二选一，两边的笔记是同一份。

【笔记存在哪】
默认不是 C 盘：有 D 盘就用 D:\写作台笔记；检测到旧数据（P:\写作台笔记 或 D:\写作台笔记）会沿用；
都没有才放「文档\写作台笔记」。设置 → 更改保存位置… 可换任意盘/文件夹，并选择是否迁移。

  笔记数据.json     主数据（不要手改）
  正文\             每篇一个 txt（人和 AI 都能直接读）
  正文\_目录.md     自动生成的多层目录大纲
  备份\             每 10 分钟自动备份，保留最近 50 份

【数据安全】
每次输入自动保存 + 10 分钟自动备份 + 历史版本；换电脑把整个笔记文件夹拷走即可。
X2.3.5 与旧版数据完全兼容，打开就是原来的文件，不会丢字。
