写作台 · 使用说明（X3.2.1）
==================================

【本版新增（X3.2.1）】
1. 设置 → 图片管理：可以扫描「未使用图片」，查看有多少张、共多大，再决定是否移到「图片-回收」文件夹。
   - 正文、所有历史版本、角色设定卡、世界观背景卡引用到的图片都会保留；
   - 10 分钟内新插入的图片不参与清理，避免刚插图还没来得及保存；
   - 只移动到「图片-回收」，不会直接删除，随时可以找回；
   - 不会自动清理，只有你点按钮并确认才执行。
2. 图片管理里也可以直接打开数据目录的「图片」文件夹。
3. 版本号：X3.2.1。

【X3.2.0 更新】
1. Word / PDF 导出现在包含正文图片：图片会按原来的位置和宽度写进文档。
2. 图片不再以 base64 塞进「笔记数据.json」，而是自动存到数据目录的「图片」文件夹；
   旧数据第一次打开会自动迁移；备份仍会把图片一起打包（备份 JSON 内嵌图片，可单独恢复）。
3. 角色表里删除有设定内容的角色时，会先弹确认，避免设定卡和设定图被误删。
4. 中文输入法组合输入结束后，会自动补上【】（）“”的收尾符号，并重新弹出角色候选。
5. 查找替换新增「区分大小写」；替换支持跨颜色/格式的文字。
6. 安装包使用代码签名（自签名证书）。Windows 仍可能显示「未知发布者」，要完全消除需要购买受信任的代码签名证书。
7. 版本号：X3.2.0。

【X3.0.0 更新】
1. 新手引导重做：
   - 一共 5 步，顶部有进度点，可以「上一步 / 下一步 / 跳过」；
   - 欢迎页先介绍自动保存、双模式、设定卡、多格式导出；
   - 后面依次是：保存位置 → 语言和角色 → 剧本模式与设定卡 → 快捷键和开始写作；
   - 最后一页可以点「新建第一个文件」直接开始，也可以点「完成」先逛逛。
2. 英文名改为 WriteDesk（意译，不再用音译 xiezuotai）；GitHub 仓库和发布页用 WriteDesk。
3. 版本号：X3.0.0（其他功能与 2.9.8 相同）。

【X3.0.0 修订（同版本 bug 修复）】
- 文件树双击展开更稳：判定窗口放宽到 600ms，兼容较慢的系统双击速度；单击只打开，双击展开/收起，小三角仍可单击。
- 剧本模式输入「【」会自动补成：`【】：“”`；如果在设置里勾选了「台词行尾加（）」，再补一对「（）」。
  选角色后会自动填进【】里，并把光标放到引号中间。自动配对后再输入同一个收尾符号（】）”）会直接跨过，不会重复。
- 左侧搜索框提示改为「搜索文件…」，避免和正文 Ctrl+F 查找混淆。
- 右键角色菜单/设定卡菜单：角色很多时不再超出屏幕（“捅破天”），菜单会固定在窗口内并且可以上下滚动。
- 普通模式里输入「【」就是普通输入（不弹角色候选、不自动补「】」）；角色名候选只在勾选「剧本模式」后生效。

【X2.9.8 更新】
1. 左侧文件树的展开/收起统一为「双击」：
   - 单击文件名只打开文件，不再自动展开；
   - 双击父文件名 = 展开 / 收起子文件；
   - 左边小三角 ▸/▾ 仍然可以单击展开/收起（这是明确的展开按钮）。
2. 深色模式按钮文字会跟着切：
   - 浅色模式时按钮显示「深色」，点它切到深色；
   - 深色模式时按钮显示「浅色」，点它切回浅色。
3. 颜色勾选改为跟「光标左边的字」的颜色一致（不再看右边）；
   选中一段文字时，按这一段开头的颜色显示。
4. 角色表和设定卡联动：
   - 角色表里新增角色并保存 → 设定卡自动多出该角色（空的设定卡）；
   - 角色表里删掉角色 / 清空角色表并保存 → 设定卡里对应角色一起删除；
   - 设定卡里点「＋ 新建角色」→ 创建后角色表自动加入这个名字；
   - 设定卡里点「删除角色」→ 角色表里同时移除。
5. 世界观背景默认空白：打开设定卡不会再自动生成一张空世界观；需要时点「＋ 新建世界观」。
6. 角色设定卡以角色表为准：角色表为空时不会残留旧角色卡；旧版自动生成的空世界观卡也会清掉。
7. 版本号：X2.9.8（含角色表/设定卡同步）。

   - 左边的小三角 ▸/▾ 仍然可以单独展开/收起；
   - 双击父文件名也仍然可以展开/收起。

4. 版本号：X2.9.6。

【X2.9.5 更新】
1. 正文查找替换（Ctrl+F）：
   - 查找框输入内容，正文里所有命中会高亮；
   - Enter / ↓ 下一个，Shift+Enter / ↑ 上一个；Esc 关闭；
   - 替换框输入后点「替换」（当前）或「全部替换」。
2. 剧本助手：
   - 打「【」自动弹角色名候选：↑↓ 选择，Enter/Tab 插入，Esc 关闭，继续打字会筛选；
   - 自动配对：【】、（）、“”、‘’、「」、『』、()、[]、{}、《》 会自动补另一半；
   - 底部状态栏实时统计：台词几句、旁白几句、描写几段、每个角色说了多少字。
3. 专注模式：顶部「专注」按钮 → 隐藏文件树 / 工具栏 / 标签 / 状态栏，只留正文；
   Esc 或右上角「退出专注」恢复。
4. 左侧新增「文件 / 大纲·速查」两个页签：
   - 大纲：按层级列出所有章节/文件，点一下跳转；
   - 速查：角色设定（含设定图/三视图缩略图）和世界观背景，点卡片直接打开设定卡。
5. 版本号：X2.9.5。

【X2.3.12 更新】
1. 剧本模式格式升级：
   - 台词行：-【角色】：“台词”（动作/情感）
     回车生成或点「插入台词行」时，会自动加「-」前缀和「（）」后缀；
   - 描写行：-描写内容，也会以「-」开头；
   - 「（）」可以在 设置 → 剧本格式 → 台词行尾加（） 里勾选/取消，取消后新生成的台词行不带括号；

2. 颜色勾选修复：光标进入台词行/描写行时，颜色那一格会正确显示这一行/这个字的颜色：
   - 默认字：浅色模式勾黑、深色模式勾白；
   - 上了色的字：勾到对应颜色；没有对应色块就收掉勾，不再停在上一操作的颜色上。
   - 说明：描写行去掉了固定的灰字，现在默认跟正文一样黑/白（保留斜体区分），所以颜色勾能正确显示。
3. 版本号：X2.3.12。

【其它功能】
◆ 导出（顶部「导出…」）：范围可选「当前文件 / 整棵树」，格式：
   TXT / Markdown / HTML / Word(.docx) / PDF / Excel(.xlsx) / PowerPoint(.pptx)
   - Word、HTML、PDF 保留颜色、荧光笔和描写行的斜体
   - Excel 两张表：目录清单 + 台词表（场景/行号/类型/角色/台词或描写/字数）
     类型列 = 台词 / 旁白 / 描写，配音、校对时直接筛
   - PPT 每篇文件一页大纲
◆ 剧本模式：每行【角色】：“文本”；回车按「回车生成」的设定生成台词行或描写行；
   Shift+Enter 永远是普通换行。
◆ 左侧层级：父文件＝文件夹图标＋加粗＋「子N · 字数」，子文件＝文件图标＋缩进引导线
◆ 语言：设置 → 语言 → 中文 / 日本語 / English
◆ 字体（顶部下拉）：幼圆、方正舒体、华文琥珀、华文彩云、楷体、华文行楷、隶书、仿宋
◆ 壁纸（设置 → 壁纸）：选图片 / 截图 Ctrl+V / 拖入图片文件；「底纹浓度」可调
◆ 多层子文件：＋子文件、行上＋、右键菜单、底部「父文件」下拉移动；双击父文件展开/收起
◆ 文字颜色、荧光笔、格线（无/横线/方格/点阵/剧本格线）、字号、深色模式
◆ 右键菜单：新建子文件 / 重命名 / 复制标题 / 展开 / 折叠 / 移到顶层 / 删除
◆ 历史版本（3 分钟一版，最多 8 版）、立即备份/恢复、打开文件夹、搜索、标签

【安装 / 升级】
双击「写作台-安装包-3.2.1.exe」→ 一路下一步，可自选安装目录（覆盖旧版即可，笔记不动）。
第一次运行若 Windows 提示「已保护你的电脑」→「更多信息」→「仍要运行」。
安装版和便携版二选一，两边的笔记是同一份。

【笔记存在哪】
默认不是 C 盘：有 D 盘就用 D:\写作台笔记；检测到旧数据（P:\写作台笔记 或 D:\写作台笔记）会沿用；
都没有才放「文档\写作台笔记」。设置 → 更改保存位置… 可换任意盘/文件夹，并选择是否迁移。

  笔记数据.json     主数据（不要手改）
  正文\             每篇一个 txt（人和 AI 都能直接读）
  正文\_目录.md     自动生成的多层目录大纲
  备份\             每 10 分钟自动备份，保留最近 50 份

【数据安全】
每次输入自动保存 + 10 分钟自动备份 + 历史版本；换电脑把整个笔记文件夹拷走即可。
X3.2.1 与旧版数据完全兼容，打开就是原来的文件，不会丢字。
