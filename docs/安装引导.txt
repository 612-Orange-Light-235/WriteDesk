写作台 · 安装引导（X3.2.1）
==================================

这个压缩包里一共三样东西：

  写作台-安装包-3.2.1.exe     ← 安装程序，双击它
  使用说明-X3.2.1.txt         ← 软件怎么用（功能、快捷键、导出）
  安装引导.txt                ← 就是本文件

【一、安装（大约 1 分钟）】
  1. 双击「写作台-安装包-3.2.1.exe」。
  2. 如果 Windows 弹出蓝色的「已保护你的电脑」窗口：
     点「更多信息」→ 点「仍要运行」。（软件没有花钱买签名证书，属正常现象）
  3. 选安装位置：默认即可；想装到别的盘就点「浏览」换一个文件夹。
  4. 点「安装」→ 等进度条走完 → 点「完成」。
  5. 桌面上会出现「写作台」图标，双击打开。

【二、第一次打开：新手引导三步】
  ① 认识界面：左边是文件树，右边写正文；每敲一个字都会自动保存。
  ② 选保存位置：建议放在空间大的盘（不用 C 盘也行）。
     点「换一个文件夹…」可以换位置，原来的稿子会一起搬过去，不会丢。
  ③ 选界面语言（中文 / 日本語 / English），填角色表（每行一个角色名，可以留空）。
  点「完成」进入正文。想再看一遍：设置 → 再看一遍新手引导。

【三、稿子存在哪】
  默认不在 C 盘：有 D 盘就用 D:\写作台笔记；检测到旧数据（P:\写作台笔记 或 D:\写作台笔记）会沿用；
  都没有才放「文档\写作台笔记」。
  设置 → 更改保存位置… 可换任意盘/文件夹，并选择是否迁移旧稿。

    笔记数据.json     主数据（不要手改）
    正文\             每篇一个 txt（人和 AI 都能直接读）
    正文\_目录.md     自动生成的多层目录大纲
    备份\             每 10 分钟自动备份，保留最近 50 份

【四、卸载】
  Windows「设置 → 应用 → 已安装的应用」里找到「写作台」→ 卸载。
  卸载只删软件，不会删你的稿子文件夹。
  如果以后还想用，重新跑一遍这个安装包即可，稿子还在原处。

【五、常见问题】
  · 杀毒软件报毒：没买签名证书，加信任即可；装完可用。
  · 双击没反应：先看看是不是已经开着一个窗口了（右下角托盘/任务栏）。
  · 换了电脑：把整个稿子文件夹（比如 D:\写作台笔记）拷过去，再把软件的保存位置指到那里。
